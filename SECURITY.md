# Security Policy

## Reporting a vulnerability

Please report security issues privately via
[GitHub Security Advisories](https://github.com/GHub942/LeaveDiscord/security/advisories/new)
or by contacting the maintainer directly. Do not open public issues for
vulnerabilities.

## Scope

This project is **complete and frozen**. It will not receive security
patches. Please note:

- Since this project is unmaintained, response times are not guaranteed.
- The site is a static, client-side HTML page with no server, no backend,
  no database, and no user data collection — there is no hosted service
  to attack.

## Supported versions

| Version        | Supported          |
| -------------- | ------------------ |
| This project   | :x: No fixes       |
