# Leave Discord

A single self-contained HTML page comparing privacy-friendly alternatives to Discord — featuring **Proton Meet** (closest match, secure and accessible) and **SimpleX** (ultimate anonymity), plus ten more options.

Available in English (default) and French, with an in-page language switch — no build step, no dependencies, no tracking.

## What's inside

- **Home** — why people are leaving Discord (including a timeline of Discord's own security incidents and its 2026 age-verification rollout), plus the two featured picks and a filterable list of other alternatives.
- **Compare** — a full feature table (end-to-end encryption, voice, video, open source, price, trust rating) across all 14 services, with Discord itself as the reference row.
- **Find your alternative** — a 5-question quiz that recommends the best 3 matches, followed by a step-by-step migration guide.

## Alternatives covered

Proton Meet, SimpleX, Stoat, Element, Signal, Zulip, Mumble, TeamSpeak, Session, Jami, Mattermost, Flackle, RootApp, Rocket.Chat.

## Usage

This is a static, single-file site: open `index.html` (or whatever you've named the exported file) directly in a browser, or host it on any static file host (GitHub Pages, Netlify, a plain web server). There is no server-side component and no build process.

## Data & accuracy

Founding dates, leak counts, and trust ratings are editorial and were accurate as of the last update noted in the page footer. Service features change quickly — always check each service's own site before migrating a community. See [CONTRIBUTING.md](CONTRIBUTING.md) if you'd like to help keep this up to date.
